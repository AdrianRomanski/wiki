# Workspace Agent Rules

## Always-On Tooling Rules

1. **Angular Code**: Always connect to the `angular-cli` MCP server (e.g. `get_best_practices`) before writing or modifying any Angular code.
2. **CSS / Styling**: Always connect to the `css` MCP server (e.g. `get_docs`, `analyze_css`) before writing or modifying styles.
3. **Documentation**: Always create or update README files / documentation artifacts after generating or refactoring code.
