# Graph Models

This directory defines the TypeScript domain models and interfaces used agcloud initcross the Wiki Graph **application**.

## Exported Types

### `NodeType`
`'entity' | 'concept' | 'source'`
The primary category classification derived from YAML frontmatter in wiki pages.

### `GraphNode`
Represents an individual node in the graph:
- `id`: Normalized unique string identifier (lowercase title).
- `title`: Display title extracted from frontmatter.
- `type`: Category (`entity`, `concept`, or `source`).
- `tags`: List of associated tag strings.
- `filePath`: Relative file path within `wiki/`.
- `isGhost`: Boolean indicating missing/unresolved wikilink target.
- `inDegree`: Count of incoming directed links.
- `outDegree`: Count of outgoing directed links.

### `GraphEdge`
Represents a directed link between nodes:
- `sourceId`: ID of the originating source node.
- `targetId`: ID of the target destination node (may reference a ghost node).

### `GraphData`
Complete graph state structure:
- `nodes`: Map of node ID to `GraphNode`.
- `edges`: Array of `GraphEdge`.
- `allTags`: Deduplicated, sorted list of all tags present in valid non-ghost nodes.

### `SimulationNode`
Extends `GraphNode` with D3 simulation properties (`x`, `y`, `fx`, `fy`).

### `WikiManifest`
Manifest payload schema generated by `wiki-cli:generate-manifest`:
- `files`: Array of relative markdown file paths.
- `generatedAt`: ISO timestamp of generation.
